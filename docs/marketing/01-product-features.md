# Movida — Product features (marketing reference)

> What Movida does today, grouped by who it serves. Use this as the source of truth for claims in posts, videos and ads.
> **Before publishing a claim**, check the "Status" column: items marked *flag* are built but switched on/off in Admin → Configuration. Only advertise what is live in production.

Tagline candidates: **"What's your next dance event?"** · "Every social. Every festival. Your crew." · "Find it. Plan it. Dance it. Stamp it."

---

## 1. Dancers — finding events

| Feature | What it means for the dancer | Status |
|---|---|---|
| **For You** home | A personal feed of upcoming events matching your styles and area, with "friends going" and "new" highlights | Live |
| **Explorer: map + list** | Every event on one map with pins grouped when close together; switch to a card list | Live |
| **Calendar view** | Day / week / month / list calendar of events | Live |
| **Filters** | Style (salsa, bachata, kizomba, zouk…), event type (social, workshop, festival, class…), area, date presets ("this weekend") | Live |
| **Text search** | Search events by name, venue, city | Live |
| **Saved searches** | Save a search (style + area + reach) and get notified when new matching events appear | Live |
| **International vs local reach** | Tag-based "international" events (congresses, festivals) vs local socials | Live |
| **Event series** | Recurring events and past editions grouped together, with reviews across editions | Live |
| **Trending** | Highlights events with the most "going" | *flag* |
| **Prices** | Free / price range shown on cards | *flag* |
| **Event pictures** | Flyers / photos on cards and detail pages | Live (*flag* for display) |
| **Auto-aggregation** | Events pulled from organisers' public Google Calendars, deduplicated, geocoded and tagged — nobody has to re-type them | Live |

## 2. Dancers — planning

| Feature | What it means | Status |
|---|---|---|
| **I'm going / Save** | One tap to RSVP or bookmark, each with its own audience: public, friends, or only me | Live |
| **See who's going** | Friends and public attendees on each event | Live |
| **My Events** | Your upcoming plan, with a route map between events | Live |
| **Festival program + My Plan** | Multi-room workshop grid; pick sessions into your personal plan; get notified when sessions change or are cancelled | *flag* |
| **Reminders** | Email / push reminders before events you're going to | Live |
| **Calendar export / subscribe** | Add events to Google / Apple calendar (ICS feed) | Live |
| **Tickets wallet** | Store your ticket (PDF, image or link) privately on the event | *flag* |
| **Promo codes** | Discount codes shared by members/organisers, moderated | *flag* |
| **Event Q&A / messages** | Ask questions, find rides, accommodation, lost & found per event | Live |
| **Reviews & ratings** | Mood, aspects (music, floor, crowd…), comments — across editions | Live (sign-in to read) |

## 3. Dancers — tracking & memories

| Feature | What it means | Status |

## 5. Organisers & community actors

| Feature | What it means | Status |
|---|---|---|
| **Free listing, zero re-typing** | Public Google Calendars are imported automatically | Live |
| **Add an event** | Guided wizard (with picture, recurrence, tags, price) — private or sent for publication | Live |
| **"I organise this event"** | Claim events, get a verified organiser badge | *flag* |
| **Hosting page** | Public page of your events on your profile | Live |
| **Edit / cancel** | Organiser edits (reviewed) and cancellation notices pushed to attendees | Live |
| **Program publishing** | Publish a festival program; changes notify everyone who planned those sessions | *flag* |
| **Followers = audience** | People who follow you get notified about your new events | Live |
| **Reviews** | Structured feedback on your events | Live |
| **Curators** | Admin-run "picks" profiles people can follow | Live |

## 6. Platform

| Feature | Status |
|---|---|
| Installable app from the browser (Android, iPhone, desktop) — no app store | Live |
| Push, email and in-app notifications, each type switchable | Live |
| Sign in with email code or Google | Live |
| Privacy-first: no ads, no trackers without consent, delete account anytime | Live |
